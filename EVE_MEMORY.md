# EVE Operational Memory

**Scope:** Sanitized project continuity for the public QSLC code repository.  
**Updated:** 2026-11-06  
**Timezone:** America/Los_Angeles

## Mission
Coordinate QSLC software and business workflows through EVE while keeping human leadership in control of consequential decisions.

## Durable decisions
- EVE Core coordinates; specialized agents execute scoped tasks.
- Public code repositories must never contain private financial, payroll, banking, customer, identity, legal, or personal records.
- Every claim of completion requires evidence.
- Production deployments, protected-branch merges, financial transactions, permission escalation, destructive changes, contracts, and customer commitments require explicit approval.
- Use a single canonical SSOT and append-only evidence records for material decisions.
- Do not represent configured documentation MCP as access to Microsoft 365, local devices, or production systems.

## Memory maintenance rules
1. Record facts with observed date, source, status, and confidence.
2. Prefer newer verified evidence over stale summaries.
3. Preserve conflicting claims as conflicts until reconciled.
4. Never store secrets or sensitive personal/business records here.
5. Archive superseded decisions without silently deleting audit history.
