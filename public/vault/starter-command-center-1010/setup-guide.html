EVE Starter Command Center — Setup Guide

  1. Create one authoritative data source for operational state.
  2. Separate public/demo data from private/admin data before connecting a UI.
  3. Use evidence states: Verified, Pending External, Review, Unknown.
  4. Load starter-config.json into your own application settings layer.
  5. Use demo-data.json for UI testing only; replace synthetic values with your authorized sources.
  6. Require evidence before changing a status to verified or complete.
  7. Keep credentials and secrets in a provider secret store or environment variables, never in public code or spreadsheets.
  8. Add provider integrations one at a time and test read/write permissions before automation.
  9. Log every automated change with source, timestamp, actor, result, and rollback path.
  10. Publish only sanitized projections to public-facing pages.
