Expanded Chapter 8 — The Cost of Fragmented Truth

A single spreadsheet can hold thousands of correct cells and still produce the wrong decision. The reason is not arithmetic; it is authority. When two files both claim to be current, every downstream dashboard becomes a negotiation. The first real problem the EVE project exposed was therefore not artificial intelligence. It was fragmentation. A founder can tolerate a messy folder for a week. A system cannot tolerate two competing truths forever.

The practical cost appears in four places. First is search cost: time spent locating the latest file. Second is reconciliation cost: comparing copies that should never have diverged. Third is decision cost: delaying action because nobody can prove which number is authoritative. Fourth is trust cost: once a dashboard has shown a stale figure, every future figure is questioned. This is why the SSOT became more important than the interface. The interface can be replaced. The authority chain cannot.

The operational answer was to give every important metric a home, a source, a timestamp, a status, and a rule for how it can be used. That sounds simple, but it changes the behavior of the entire system. A number stops being a decoration and becomes an evidence object. A formula stops being a clever equation and becomes a transformation with lineage. A task stops being a reminder and becomes a state transition: pending, evidenced, approved, executed, reconciled.

This is also where the founder story becomes reproducible. The achievement is not that one person clicked every button. Expanded Chapter 9 — Numbers Need Labels Before They Need Hype

A dashboard number can be precise and still be misunderstood. The October corrected master workbook contains values for total value, liquid assets, an IP floor, PSI supply, a reference price, system uptime, security, and project progress. Precision does not automatically make those numbers market facts. The publishing rule for this series is stricter: every metric must carry a label describing what it actually is.

An internal valuation is an internal valuation. A model output is a model output. A public market price is a public market price only when an external source supports it. A configured constant is not a measurement. A software KPI is not a law of physics. This distinction protects the reader and protects the work. It makes the interesting claims stronger because the book does not need to pretend that every number has the same evidentiary status.
